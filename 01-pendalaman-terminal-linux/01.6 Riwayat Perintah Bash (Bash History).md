**Riwayat Perintah Bash (Bash History)**

Bash secara otomatis menyimpan riwayat perintah yang dijalankan pengguna untuk meningkatkan efisiensi dan produktivitas.

	**Lokasi & Konfigurasi**

	- Riwayat disimpan di: ~/.bash_history
	- Jumlah perintah di file: HISTFILESIZE
	- Jumlah perintah di memori: HISTSIZE

	**Cek nilainya:**

	echo $HISTFILESIZE
	echo $HISTSIZE

	**Melihat & Menggunakan Riwayat**
	Tampilkan riwayat:
		history

	Jalankan perintah berdasarkan nomor:
		!17

	Jalankan perintah terakhir:
		!!

	Jalankan perintah ke-n terakhir:
		!-3

	Jalankan perintah terakhir dengan nama tertentu:
		!ping

	Gunakan hati-hati, karena perintah langsung dieksekusi.
	Cek Sebelum Eksekusi
		!ping:p

	Menampilkan perintah tanpa menjalankan.

	Navigasi Riwayat
		↑ / ↓ atau Ctrl + P / Ctrl + N

	Cari cepat:
		Ctrl + R → ketik kata kunci
		Enter untuk eksekusi
		Ctrl + G untuk batal

	**Menghapus Riwayat**

	Hapus satu baris:
		history -d 10

	Hapus semua:
		history -c

	**Catatan Penting**

	- File .bash_history baru diperbarui saat logout
	- Riwayat Bash adalah fitur penting untuk kerja cepat & audit command
