#pendalaman terminal linux

Folder ini berisikan dokumentasi dan catatan teknis mengenai penggunaan **terminal linux** sebagai fondasi utama dalam memahami sistem linux.

materi disusun untuk membangun pemahaman konseptual dan kemampuan praktis dalam bekerja dengan command line, mulai dari pengenalan terminal hingga penggunaan perintah secara efektif dan efisien.

#cakupan materi
 - terminal, console dan shell
 - struktur perintah linux
 - perintah dasar dan lanjutan
 - input, output, redirect, pipe
 - manual dan sistem bantuan ('man', 'help')

Dokumentasi dilengkapi dengan contoh perintah dan lab praktikum sederhana sebagai pendukung pembelajaran.
