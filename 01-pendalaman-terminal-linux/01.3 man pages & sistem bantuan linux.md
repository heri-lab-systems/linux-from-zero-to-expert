# Man Pages & Sistem Bantuan Linux

Linux memiliki ratusan perintah dengan banyak opsi, sehingga mustahil menghafal semuanya.  
Untungnya, Linux menyediakan **sistem bantuan bawaan** berupa *manual pages* atau **man pages**.

## Apa itu Man Page?
**Man** adalah singkatan dari *manual*.  
Man page berisi dokumentasi resmi sebuah perintah atau program di Linux.

Untuk membukanya:

    man <nama-perintah>

    Contoh:

    man ls


Secara default, man page ditampilkan menggunakan program less (pager untuk membaca teks).

Navigasi Dasar di Man Page

    ↑ / ↓ → pindah baris

    Space / Ctrl + F → maju satu layar

    Ctrl + B → mundur satu layar

    g → ke awal halaman

    G → ke akhir halaman

    /kata → cari dari atas

    ?kata → cari dari bawah

    n → hasil berikutnya

    N → hasil sebelumnya

    q → keluar

    Tekan h untuk melihat ringkasan bantuan less.

**Struktur Umum Man Page**

 - NAME
    Nama perintah dan deskripsi singkat

 - SYNOPSIS
    Cara formal menjalankan perintah

 - [opsi] → opsional

 - ... → dapat diulang

 - DESCRIPTION
    Penjelasan lengkap perintah

 - OPTIONS
    Daftar opsi yang tersedia

 - SEE ALSO / AUTHOR / COPYRIGHT

Konvensi Penting
 - Teks tebal → ketik persis seperti yang tertulis
 - Teks miring/garisbawah → ganti dengan nilai yang sesuai
 - Opsi pendek dan panjang (-a, --all) berarti bisa digunakan salah satu
 - Perintah Executable vs Built-in Shell
 - Linux memiliki dua jenis perintah:
 - Executable file (memiliki man page)
 - Built-in shell command (tidak punya man page khusus)


**Untuk mengecek jenis perintah:**

    type <nama-perintah>


Contoh built-in:

    cd, alias, umask

Gunakan:

    help <nama-perintah>

    Contoh:

    help cd

    Opsi --help

Hampir semua perintah mendukung bantuan singkat:

    ls --help
    rm --help
    cd --help


Berlaku untuk perintah executable maupun built-in.

Mencari Perintah di Semua Man Page

Gunakan:

    man -k <kata-kunci>

    atau:

    apropos <kata-kunci>


    Contoh:

    man -k ifconfig
    apropos uname
    man -k "copy files"
