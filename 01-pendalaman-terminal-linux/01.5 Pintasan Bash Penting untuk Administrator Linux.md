##Pintasan Bash Penting untuk Administrator Linux

Seorang administrator Linux menghabiskan sebagian besar waktunya di terminal. Menguasai pintasan Bash adalah kunci untuk bekerja lebih cepat, efisien, dan minim kesalahan.

    **Pintasan Wajib Diketahui**
    Pintasan	Fungsi
    Ctrl + L	Membersihkan layar (seperti clear)
    Ctrl + D	Keluar dari shell (seperti exit)
    Ctrl + A	Pindah kursor ke awal baris
    Ctrl + E	Pindah kursor ke akhir baris
    ↑ / ↓	Navigasi riwayat perintah
    Ctrl + U	Menghapus seluruh teks sebelum kursor
    Ctrl + C	Menghentikan proses yang sedang berjalan
    Ctrl + Z	Menjeda (suspend) proses sementara

    **Contoh Penggunaan Nyata**

    Mengganti perintah dengan cepat:
        Ambil perintah sebelumnya (↑)

    Ctrl + A → ganti nama perintah

    Menghentikan proses yang berjalan lama:
        Ctrl + C (misalnya ping atau wget)

    Menjeda proses sementara:
        Ctrl + Z, lanjutkan dengan bg

    ##Catatan Penting

    - Ctrl + C menghentikan proses, Ctrl + Z hanya menjeda.
    - Ini konsep penting bagi sysadmin dan DevOps.
